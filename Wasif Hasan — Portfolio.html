Projects

Hands-on MikroTik labs from my own practice and study.

ISP lab: chasing down a dead WAN path

Built a basic ISP configuration on a MikroTik CHR router in VirtualBox — LAN, static WAN, NAT, and DNS. Hit 100% packet loss pinging 8.8.8.8, traced it to a virtual WAN gateway that didn't actually exist, fixed the VirtualBox networking, and switched the WAN to a DHCP client. Result: clean 0% packet loss.

MikroTik CHR Troubleshooting

Multi-session eBGP over VLANs

Set up four BGP peering sessions across VLAN trunks between an IIG and an ISP router on RouterOS v7, with separate VLANs for Global Internet, GGC, FNA, and BDIX. Resolved BGP sync issues (Local Role/AFI mismatches) while working with simulated routing tables of 7,000+ BDIX prefixes.

BGP RouterOS v7 VLANs

WAN configuration: DHCP, static & PPPoE

Configured and compared three MikroTik WAN methods on a bridged lab network — a DHCP client walking through the DORA process, a static IP WAN with manual routing and DNS, and a PPPoE client authenticating with custom credentials — to understand how each acquires and passes upstream connectivity.
